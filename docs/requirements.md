# 企画書の要約と今回の実装範囲

利用者から提供された「乗り換えナビ企画書.md」の内容を、開発対象として整理したものです。未記載の仕様は確定要件として扱っていません。

## 企画の目的

大分県中津市で、スマホを使い始めた高齢者が、自宅にいながら目的地までのバスの乗り継ぎを調べられるようにします。デマンドバスによる路線バスへの接続と、その後の乗り換え案内を一連の流れにします。主な利用端末はスマートフォンです。

## 企画書で示された流れ

1. 最初の登録時に地図から自宅の場所を設定する。
2. 目的地と到着希望時刻を入力する。
3. 路線バスの通る地点までのデマンドバスを申し込む。
4. 路線バスに接続した後も、目的地までの案内を確認する。

## 今回実装した体験版

| 企画書の内容               | 今回の動作                                                                             | 実運用に必要なもの                                   |
| -------------------------- | -------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| 自宅の登録                 | ニックネーム、地域・航空写真上の位置・明示的に選んだ現在地をブラウザ内へ保存           | 住所確認、必要に応じたアカウントと本人確認の仕様     |
| 目的地と到着希望時刻の指定 | 中津市内の代表施設を選び、日付・時刻を指定                                             | 自由な目的地入力や対象範囲の仕様                     |
| バスの経路検索             | 合成時刻表による徒歩・デマンドバス・路線バスの候補表示                                 | 公式時刻表・運行日・乗継条件などのデータと経路検索   |
| デマンドバスの申込         | 内容と未送信の注意を確認し、体験用の予定として保存                                     | 対象地域・資格・予約条件、事業者の実予約システム     |
| その後の案内               | サンプル経路を手順ごとに表示、対応環境で音声読み上げ。許可した端末の現在地を地図に表示 | 実際の経路・運行情報、安全な徒歩経路、位置精度の検証 |

文字サイズ切り替え、大きめの操作ボタン、使い方案内、予定の個別削除と登録情報の全削除も追加しています。

## 航空写真と位置情報の扱い

追加要望に合わせて、国土地理院の航空写真とブラウザの位置情報を使用します。航空写真と位置取得は初期状態では停止し、利用者が操作して有効にします。GPS には HTTPS とブラウザの許可が必要です。実際の位置が表示されても、時刻表・バス停・バス経路は引き続きサンプルです。

航空写真は [地理院タイル](https://maps.gsi.go.jp/development/ichiran.html) の `seamlessphoto`（ズーム2〜18）を使用します。API キーは不要で、[国土地理院コンテンツ利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html) に従い出典を表示します。航空写真はリアルタイムではなく、地域により撮影時期や精度が異なります。

本人の自宅・現在地を他の利用者に共有する機能は設けません。現在地は画面のメモリ上で扱い、移動履歴を保存・送信しません。停止操作、地図・画面を閉じたとき、タブの非表示で取得を停止します。「現在地を自宅に設定」で選び、登録を保存した場合のみ、自宅情報としてブラウザ内へ保存します。予定にも保存時点の自宅情報が残るため、削除は自宅登録と予定の両方を対象にできます。

航空写真を有効にすると、画像の取得先である国土地理院へ IP アドレスと閲覧範囲に対応するリクエストが送られます。画面でその説明を確認したうえで利用します。精密な自宅マーカーやニックネームを外部共有する処理はありませんが、すべての位置に関する外部通信がなくなるわけではありません。

サイト自体は GitHub Pages の公開サイトのままで、閲覧者を本人だけに制限する認証は追加していません。同じ端末・ブラウザを共用する場合には、保存情報の削除が必要です。

## 未確定・未連携の仕様

企画書には、実際の運行データの提供元、予約の受付方法、対象地域・利用資格、認証方式、運用主体は記載されていません。今回の実装には、実予約の送信、実アカウント、端末間同期、実際の道順によるナビゲーション、オフラインでの再読み込みは含めていません。GPS 表示は実際の道路・運行経路に沿った案内や、安全な道順の保証ではありません。

表示する時刻・運賃・バスの経路は操作検証用であり、運行条件や予約受付を示すものではありません。航空写真の取得と端末の位置精度は、実際の利用環境でも確認する必要があります。
